# 📘 K-Skill App

**K-Skill** is a mobile learning app designed to help rural government school students (Classes 8–10) learn **spoken English** through structured lessons, interactive practice, assessments, and fun activities.

🌐 Web Version: [K-Skill Web](https://k-skill.vercel.app)

---

## 🚀 Features

- **Assessments** – Grammar, Vocabulary, Reading, Listening with personalized level recommendations  
- **Vocabulary Builder** – Theme-based word categories (Travel, Food, Hospital, etc.) with audio & examples  
- **Dictionary** – Bilingual (English → Telugu), phonetics, audio pronunciation, example usage  
- **Learning Modules** – Level-wise lessons (Basic → Advanced), academics (Classes 8–10), discourses practice  
- **Practice** – Reading aloud, speaking with AI, listening drills, chatbot for instant support  
- **Games** – Word match, sentence formation, listening puzzles, story completion & more  
- **Profile Dashboard** – Student progress, streaks, assessment tracker, quiz scores  

---

## 📂 App Structure

1. **Home** – Assessments, Vocabulary, Dictionary, Reading  
2. **Learning** – Level-wise lessons, academics, discourses  
3. **Practice** – Reading, Speaking, Listening, Chatbot  
4. **Games** – Interactive educational games  
5. **Profile** – Progress tracking & personal dashboard  

---

## 🛠️ Tech Stack

- **Frontend:** Flutter (Dart)  
- **Backend:** Node.js + Express  
- **Database:** MongoDB Atlas  
- **AI Integration:** GPT models for speaking/chatbot & feedback  
- **Authentication:** Email + OTP verification
